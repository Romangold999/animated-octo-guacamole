# WB Скидки

Android-приложение для поиска товаров Wildberries со скидкой **строго больше 50%**. Telegram полностью удалён: находки сохраняются локально и отображаются карточками внутри приложения.

## Возможности
- Поиск по нескольким категориям Wildberries.
- Карточки с изображением, названием, брендом, ценами и рассчитанной скидкой.
- История находок без повторов по nmId (до 500 карточек).
- Поиск по найденным товарам и переход к товару на Wildberries.
- Сканирование в активной сессии приложения.

## Сборка APK
Откройте вкладку Actions, выберите Build Android APK и нажмите Run workflow. После успешного выполнения откройте запуск workflow и скачайте артефакт WB-Skidki-debug-APK. Каждый push в main запускает сборку автоматически.

## Ограничения
Wildberries может менять HTML-разметку, ограничивать запросы или показывать CAPTCHA. Приложение не обходит защиту и не гарантирует непрерывный сбор данных. Сканирование работает, пока приложение открыто.
